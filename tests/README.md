# Teststruktur

- `unit/`: domene- og state-machine-tester
- `integration/`: API/Supabase/realtime-livssyklus
- `realtime/`: reconnect, sekvensering og degradering
- `translator-benchmark/`: versjonerte fixtures og måleresultater
- `learning/`: progresjon, mastery og review
- `rls/`: anonym/eier/kryssbruker/admin-grenser

Audio-fixtures skal være syntetiske, lisensierte eller eksplisitt godkjent og må ikke inneholde private samtaler.
