# Translator benchmark

Mål: first-partial latency, useful-translation latency, finalization latency, WER, translation adequacy, speaker attribution, language ID, TTS-start, reconnect og dropped segments.

Miljømatrise: stille rom, bil/taxi, gate, marked/restaurant, vind og bakgrunnsmusikk; én til tre talere, overlapp og Darija/fransk kodeveksling.
